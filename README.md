# Vectora 矢量路径工具

安装：Node.js 22 环境下执行 `npm ci`。

本地启动：`npm run dev`，打开终端显示的地址。

Docker 启动：`docker compose up --build`，访问 http://localhost:8119。

## 变形（Warp）

选中一个图形或一个组，在左侧 WARP 面板中选择一种变形：

- **四角透视**：拖动四个角，把平面图案贴到倾斜包装盒之类的透视面上。要求四个角保持凸四边形，否则会压扁、翻面或边界自交，这些情况会在提交前被拒绝，并保留上一个有效状态。
- **自由包络**：5×5 的包络网格，边界点和内部点都可以拖动。网格线与边界线按当前曲面实时绘制；每个控制点的位移只影响相邻四格，拖动时手柄与指针 1:1 跟随。

两种模式共享同一套底层曲面（透视基面 + 偏移场），因此来回切换不会让画面跳动；如果自由包络的内部编辑无法用四角表示，切换时会给出提示，且可以撤销找回。

### 共用变形空间

同一个组里的所有图形固定使用同一个 `WarpSpace`（`doc.warps` 中一条记录，按组 id 索引）。因此组的成员始终一起变形，相邻图形的公共边界被映射到完全相同的曲线，接缝不会裂开。未编组的多个图形不允许直接加变形——面板会提示先编组；把已有变形的图形和普通图形编组时，新组会继承那条变形空间。

### 轮廓近似

曲线经过变形后一般不再是原来的三次贝塞尔，所以需要重新拟合：

- 每个原始段按误差预算自适应采样，再用 Schneider 最小二乘 + 自适应分裂拟合三次段；
- 拟合结果会针对精确映射再次校验，不满足 `tolerance` 就收紧采样预算重拟合，确保误差上界可信；
- 面板里的 "Outline accuracy" 决定误差预算，并实时显示节点数与实测最大误差；
- 预览、展开与导出使用同一精度；放大画布只会追加细节，不会露出比导出版本更粗糙的近似。

### 展开与保留效果

- **Expand effect**：把当前近似写成普通节点（`warp.baked`），可以直接用节点工具编辑；原始路径仍然保存在 `shape.nodes` 里，成为效果的底稿。
- **Restore effect**：丢弃烘焙结果，按原稿重新实时计算。展开/还原永远从原稿重新生成，所以反复切换不会累积误差，也不会改动颜色、描边、透明度或图层顺序。
- **Release**：移除效果，并把当前可见结果留作普通路径（原始节点若已烘焙则被替换）。

### 限制与反馈

- 提交前对雅可比行列式做逐格采样 + 边界简单多边形检查，拒绝翻面、自交、近乎退化的映射；
- 拖动过程中非法位置会被跳过，手柄停在最后一个有效位置并给出原因；底部状态栏与 WARP 面板同时显示，面板边框变红；
- 撤销/重做记录 `shapes + warps` 快照，单次拖动只占一个撤销步；本地存储带结构校验，损坏的变形数据会被丢弃并回退到原稿。
